## Resumo
# TPC4 - Aplicação de Listas de Inteiros

Repositório dedicado à resolução do TPC4, que consiste no desenvolvimento de um programa em Python para a gestão e manipulação de listas de números inteiros através de um menu interativo no terminal.

## Funcionalidades do Programa

O menu apresenta as seguintes opções de operação:

* **(1) Criar Lista**: Gera automaticamente uma lista com números aleatórios entre 1 e 100, substituindo a anterior.
* **(2) Ler Lista**: Permite a introdução manual dos elementos da lista pelo utilizador.
* **(3) Soma**: Calcula o somatório total dos elementos presentes na lista.
* **(4) Média**: Calcula a média aritmética dos valores armazenados.
* **(5) Maior**: Identifica o maior elemento da lista.
* **(6) Menor**: Identifica o menor elemento da lista.
* **(7) Ordem Crescente**: Verifica se a lista se encontra ordenada por ordem crescente.
* **(8) Ordem Decrescente**: Verifica se a lista se encontra ordenada por ordem decrescente.
* **(9) Procurar Elemento**: Procura um valor específico e devolve a respetiva posição, ou -1 caso o elemento não pertença à lista.
* **(0) Sair**: Encerra a aplicação e apresenta a lista final guardada em memória.

## Aspetos Técnicos

* Controlo de fluxo através de um ciclo principal para a repetição contínua do menu.
* Implementação de validações para assegurar que a lista não se encontra vazia antes da execução de operações de cálculo ou pesquisa.
* Utilização de estruturas de repetição (`for` e `while`) e condições (`if`, `elif`, `else`) para o processamento lógico dos dados.
