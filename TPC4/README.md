## Resumo
Aplicação desenvolvida em Python para a gestão e processamento de listas de números inteiros através de um menu interativo no terminal. O programa permite criar listas de forma automática com valores aleatórios ou de forma manual, realizar cálculos como somas e médias, encontrar os valores máximos e mínimos, verificar a ordenação crescente ou decrescente, e procurar elementos específicos com devolução de posição ou do valor -1. Conta também com validações de segurança para impedir operações em listas vazias.
