## Resumo
Este trabalho consiste num programa desenvolvido em Python, estruturado através de um menu interativo para a gestão de dados de uma turma. A informação relativa aos alunos é armazenada numa lista de tuplos, seguindo o modelo que integra o nome, o identificador único e uma lista com as respetivas notas de trabalho de casa, projeto e teste.

O projeto cumpre integralmente os requisitos propostos, permitindo criar e inserir novos alunos, listar a turma completa, consultar registos específicos por ID e assegurar a persistência dos dados através da gravação e leitura de ficheiros de texto com recurso ao delimitador #. Do ponto de vista técnico, o código garante uma organização rigorosa através da separação entre as funções modulares e o ciclo principal de execução.
