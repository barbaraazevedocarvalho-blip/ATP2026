## Resumo
O TPC1 foi realizado na plataforma **"Blockly Games"** e dividiu-se em duas partes:

A primeira parte foi realizada no jogo **Turtle**. Depois de praticar a lógica de programação nos primeiros níveis, apliquei os conhecimentos e prática obtidos para executar a figura fornecida pelo professor.
O objetivo na segunda parte foi resolver o nível 10 do jogo **Maze** do mesmo site, recorrendo ao raciocínio lógico para guiar a personagem até ao fim do labirinto.
